Marketplaces

Connect eBay, Depop, Etsy, and Poshmark with OAuth (Poshmark uses email and password). Facebook Marketplace connects with the Chrome extension.

Facebook Marketplace uses the Crosslist Connector Chrome extension. For other stores, the extension is an optional backup. In Chrome: chrome://extensions → Developer mode → Load unpacked → select the extension folder in this project, then refresh this page.
